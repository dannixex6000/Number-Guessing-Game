# Number-Guessing-Game
When you run this game, you will be given a number, and you have to guess the number via the following rules:
1. I will choose a number between 1 and 100
2. When a number is guessed, the user is told if the actual number is higher or lower
3. The user will get a certain number of guesses, depending on the level of difficulty
4. When a number is guessed, the number must be a whole number; going above 100 or below 1 is up to the user
